# Source License Data Dictionary

| Column | Description |
|---|---|
| `source_key` | Stable project key for the source. |
| `source_name` | Human-readable source name. |
| `source_url` | Canonical source URL. |
| `license_name` | License or terms label. |
| `license_url` | License URL when available. |
| `attribution_required` | Whether public outputs must credit the source. |
| `non_commercial_only` | Whether source use is limited to non-commercial outputs. |
| `share_alike_required` | Whether derived outputs may have share-alike obligations. |
| `redistribution_allowed` | Whether raw redistribution is allowed. |
| `commercial_use_allowed` | Whether paid/commercial outputs are allowed. |
| `status` | Project handling status: `target`, `reference`, `fallback`, or `isolated`. |
| `notes` | Source-specific caveats. |
