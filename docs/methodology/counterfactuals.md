# Counterfactuals

Counterfactuals must be framed as measurable component changes.

Good form:

> If Player A improves second-serve points won by 2 percentage points, holding other modeled components constant, expected match win probability changes by Z.

Avoid vague or causal-overclaiming versions such as “what if the player became more clutch” unless the component is explicitly defined and modeled with caveats.

## Required Caveats

- Observational data does not prove causality by itself.
- Surface and opponent mix can change component stability.
- Small samples need shrinkage or uncertainty intervals.
