# Serve/Return Models

Serve and return decomposition should explain why a player is projected to win or lose, not only assign a probability.

## Default Components

Serve:

- First-serve percentage.
- First-serve points won.
- Second-serve points won.
- Ace rate per service point.
- Double-fault rate per service point.
- Service points won.
- Hold percentage.

Return:

- Return points won.
- First-serve return points won.
- Second-serve return points won.
- Break percentage.

Every rate must include sample size, time window, surface context, and missingness caveats.
